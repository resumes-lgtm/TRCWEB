# The Resume Chic Website

High-fidelity static website build based on the approved designs.

## Pages
- `index.html`
- `services.html`
- `success-stories.html`
- `service-finder.html`

## Run locally
Open `index.html`, or run `python -m http.server 8000` in this folder.

## Before launch
1. Replace service-finder email links with Stripe Payment Links.
2. Configure Stripe success URLs to redirect to the matching Cognito onboarding form.
3. Replace cropped mockup imagery with final licensed brand photography for maximum resolution.
4. Add your production domain, analytics, privacy policy, and form integrations.
